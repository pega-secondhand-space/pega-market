## ✨ 核心特色與體驗架構

### 1. 📱 手機端極致觸控體驗 (Mobile-First)
- **預設 🍎 階差大卡模式 (Apple Showcase Mode)**：黑曜石玻璃卡片配合巨大琥珀金浮水印序號（`01`, `02`, `03`...）與 `NO. 01` 王座徽章。
- **頂部快速切換膠囊**：隨時一鍵切換 `[ 🍎 階差大卡 ]`、`[ 📱 串文 (Threads 流) ]` 或 `[ ▦ 雙排方格 ]`。
- **置底懸浮金色導覽列**：黃金觸控區中央大圓 `+` 刊登按鈕、即時搜尋、留言板與管理入口。
- **iOS 邊界與手勢適配**：自動適配 iPhone Home Bar 安全區（`safe-area-inset-bottom`），支援詳情彈窗下滑手勢直接關閉與遮罩背景點擊關閉。

### 2. 💻 PC 電腦端寬螢幕高效率體驗 (Desktop)
- **頂部常駐導覽列**：右上方配置流金質感 **`[ 🎁 我要刊登 ]`** 按鈕，隨時隨地 1 鍵刊登。
- **工具列排版下拉選單**：支援 `雙排 2 卡 (預設)`、`三排 3 卡`、`四排 4 卡 (寬螢幕)` 自由切換。
- **全域 `ESC` 鍵一鍵關閉**：按下鍵盤 Escape 鍵即可瞬間關閉任何彈窗，操作順暢極速。
- **專屬大尺寸數據表格**：留言板與貼文管理提供寬螢幕多選 Checkbox、批次操作與全螢幕（`98vw`）切換。

### 3. 🎁 刊登流程 ❶ ❷ ❸ ❹ 階梯步驟引導
- **❶ 步驟 1：選擇交易類型 【必選】**（💰 我想賣、🔍 我想買、🎁 免費送、🎉 尾牙全新）。
- **❷ 步驟 2：物品名稱與價格 【必填】**（以物易物切換、0 元免運智慧帶入、9 折/95 折折價計算小幫手）。
- **❸ 步驟 3：商品照片上傳 【必填】**（第一張主圖【必填】標記、第二張細節【選填】、智慧前端壓縮預覽）。
- **❹ 步驟 4：聯絡資訊與 4 位數自刪 PIN 碼 【必填】**（自動快取記憶同仁暱稱與聯絡資訊、自動隨機生成 PIN 碼）。
- **⚙️ 更多選填補充項目**（折疊式 `<details>`：物品詳細補充描述、自動下架天數設定）。

### 4. 🏆 動態時序流模式（觀點 A）
- 最新刊登的商品自動登上首頁最頂部，獲得金色 **`NO. 01`** 徽章與背景浮水印 **`01`**。
- 成交後商品自動呈現優雅黑白灰階沉浸狀態，並啟動 **24 小時自動倒數下架** 移入歷史成交庫。

### 5. 🛠️ 完善的後台管理與維護系統
- **💬 留言板批次管理**：支援多選全選、批次刪除與版主官方回覆。
- **🤝 歷史成交存檔庫**：支援多選批次刪除與 **「🧹 一鍵清空所有存檔」**。
- **📋 貼文批次管理**：支援搜尋、類型篩選、置頂與強制下架違規貼文。
- **📢 全站使用須知廣播**：永久置頂顯示，支援版主自訂預設範本與雲端同步。
- **🟢 全站即時在線監控**：30 秒 Heartbeat 心跳同步，秒級統計活躍同仁數。

## 🛠️ 技術棧與架構

- **前端核心**：Vanilla HTML5, Vanilla JavaScript (ES6+ 模組化架構), Vanilla CSS (TailwindCSS CDN)
- **雲端資料庫與存儲**：Supabase (Postgres Database, Storage Bucket, RPC Functions, Presence Heartbeat)
- **安全防護**：全站 XSS `escapeHtml` 跳脫、Postgres RPC 權限隔離、SHA-256 版主與 4 位數 PIN 碼雜湊驗證
- **測試體系**：33 項真實使用者旅程模擬測試 + 44 項端到端自動化測試套件（100% PASS）
